Test build (Android)

Download StatusKeep APK – latest test version for Android 7 and above.

  1. Open the link on your Android phone and download the file.
  2. Tap the downloaded file. If asked, allow your browser or Files app to install unknown apps.
  3. Tap Install. Updating to a newer test build keeps your settings.

This is a test build for trying the app before it is on Google Play. If Play Protect warns about an unknown developer, tap More details → Install anyway.
